# Macro Event Tracker

This project tracks how major markets react to key macroeconomic events.

The idea is simple: after important releases (CPI, NFP, central bank decisions, etc.), I record how different assets move in the minutes and hours following the announcement.

The goal is to build intuition around how macro news actually transmits into markets.

Assets I track include:

- FX (EUR/USD, USD/JPY)
- Rates (US 10Y yields)
- Equities (S&P 500 futures)
- Commodities (gold, oil)

Over time this should create a small dataset of event reactions that can be used to spot patterns in market behaviour.
